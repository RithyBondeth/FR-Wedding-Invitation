## Overview

FR Wedding Invitation is an elegant, mobile-friendly digital wedding invitation. Guests scroll through a sequence of sections covering the couple, the celebration details, and the venue, which includes an embedded map.

## Features

- **Six themed sections** that guests scroll through.
- **Embedded venue map.**
- **Responsive design** for phones, tablets, and desktops.

## Getting Started

### Prerequisites

- Node.js and npm

### Installation

```bash
git clone https://github.com/RithyBondeth/FR-Wedding-Invitation.git
cd FR-Wedding-Invitation
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

### Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the development server |
| `npm run build` | Create a production build |
| `npm run start` | Serve the production build |
| `npm run lint` | Run ESLint |
